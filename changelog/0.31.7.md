# 📣 What's new in 0.31.7

## 📌 A pinned message under every CTA
Every CTA can now carry your guild's standing message, such as the rules, the gear check or links to other channels. The bot forwards it right below the CTA roster and pins it, so it is one tap away in the pinned messages.
Channel links in the message keep working. Nobody gets pinged by it, even if the message mentions roles or everyone.

**For admins: how to set it up**
1. Find the message you want under every CTA. Right-click it (or long-press on mobile) and choose **Copy Message Link**.
2. Run `/content setup` and paste the link into the **cta-msg** option.
3. Give the bot **Pin Messages** in the CTA channel, and **Read Message History** in the channel of that message.

From then on, every new CTA gets it. To change the message, run `/content setup cta-msg` again with another link. To remove it, use **clear-cta-msg**. CTAs made before keep the message they were made with.
If the bot cannot forward or pin the message, the CTA is still created and the person who made it gets a private note saying why.
