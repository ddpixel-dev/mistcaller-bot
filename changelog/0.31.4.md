# 📣 What's new in 0.31.4

Presets are now quick to save and fill the whole card in one pick.

## 💾 Manage presets
On the creation card, next to **Blank template**, there is a new **Manage presets** button. It is for admins only (the admin roles set in `/content setup`, and anyone with Manage Server).
• **Save as preset** keeps the card as it is now, once it is ready to create. Give it a name. A name that already exists is replaced.
• **Delete preset** removes a preset. Choose it, then confirm. Nothing is deleted until you confirm.
Press **Back to the card** to carry on.

## 📋 One pick fills everything
A preset now keeps the type, category, loot vote, sign-up mode, title, gear tier, notes, build link and positions. Only the start time is left out, so you set that each time. Choose a preset and the whole card is filled in.
**Choose from preset** is now the first menu on the card. Presets saved earlier still work: they fill the positions only.

## 🧹 The /content preset command is gone
Saving a preset happens on the card now, so the old `/content preset` command has been removed.
