# 👥 What's new in 0.33.0

## 👥 Two parties for any event
Any event can now have **two parties**, not only CTAs.
- **Hosts:** on the creation card, pick **How many parties? → Two Parties**. Type party 1 in **Details**, then press **Party 2 slots** (or **Copy party 1** to start from the same list).
- The event's post shows both parties in one roster. Each party has its own menu, fills and waitlist.
- Later, change party 2 with **Edit content → Edit → Edit party 2 slots**.

## 🧩 Setup Slots
- The **Roles** button is now **Setup Slots**.
- On a two-party card it first asks **which party** to set up, then fills only that party. This works for CTAs too, where it used to fill party 1 only.

## 🗂️ Where events are posted
- **PvE** events go to the **PvE forum**. **PvP, PvX and ZvZ** events all go to the **PvP forum**. CTAs stay in the CTA channel.
- **Admins:** `/content setup` with `forum-type` now offers only **PvP** and **PvE**.
