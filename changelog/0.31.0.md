# 📣 What's new in 0.31.0

A new, simpler way to create content, and a calendar that separates call-to-arms events.

## ✨ Create content from the content-management channel
`/content create` is gone. In the content-management channel (the one with the calendar), the top message now has two buttons:
• **Normal content** opens your creation card, as before: type, category, loot vote, sign-up mode, **Details**, **Roles** for the slots, then **Create**. The bot makes the event's post in the forum that matches its type (PvP, PvE or PvX).
• **Special content (CTA)** is for a call to arms. Only admins and members with a CTA role can use it. It is announced in the CTA channel, and its roster lives in a thread under the announcement.

The old **Create event** posts at the top of each forum are removed.

## 📄 Blank template
For something the bot has no type for, press **Blank template** on the creation card. It skips the slots and asks for just a **title, start time, gear tier and description**. The post has no roster, no sign-up and no loot vote. You can still edit, lock, end or cancel it. Normal content needs its type (PvP or PvE) picked first, so the bot knows which forum to use. A blank CTA needs no type.

## 📅 A clearer calendar
Call-to-arms events now come first under each day, in their own **📣 Call to arms** group, with the normal content below. The creation buttons live in a message of their own above the calendar. You can also press **Roster** on the bot's posts in an event to jump back to the roster.

## 🎯 Selection events
If the owner of a selection event signs up, they are seated right away instead of applying. The note in the post now reads **⚠️ Disclaimer: the host picks the party.**

## 🗂️ Categories
**Outposts** is now **Outpost**.

## 📢 For admins
• Set the **CTA channel** with `/content setup` → `cta-channel` (a text channel), and choose the roles that may create CTAs in the second role picker of `/content setup`. The bot needs View Channel, Send Messages, Create Public Threads, Send Messages in Threads, Manage Threads and Pin Messages there.
• Event forums need no launcher post any more. Give the bot **Create Posts, Send Messages in Posts, Manage Threads and Pin Messages** in them.
• The content-management channel is the calendar channel you already set with `calendar-channel`. Rename it in Discord if you like.
