# 📣 What's new in 0.31.3

New names for the creation buttons, one forum for each kind of content, and an easier way to choose who can schedule call-to-arms events. This also covers 0.31.2.

## ✨ Clearer buttons
In the content-management channel, **Normal content** is now **Plan Content**, and **Special content (CTA)** is now **Schedule CTA**. They work exactly as before.

## 🗂️ One forum for each kind of content
Admins now choose the forum for **PvP**, **PvE** and **PvX** separately. The old "Any" choice is gone. Want PvX events in your PvP forum? Pick that forum for PvX as well. One forum can take as many kinds as you like.
• If a kind has no forum yet, the bot tells you when someone tries to plan it, and what to do about it.
• Servers that already had forums set up keep working exactly as before.

## 📣 Choose who can schedule a CTA
Admins can add a role right from the setup command, with no extra panel to open. Use **cta-role** to add a role and **remove-cta-role** to take one away. Repeat it to add more roles. Admins can always schedule a CTA.

## 📋 The Preset menu is always there
The creation card now always shows the **Preset** menu. If your server has no presets yet, it is dimmed and tells you how to save one with `/content preset save`. Presets belong to each server, so a server starts with none.

## 📜 Changelogs in a thread
Admins can now send the changelog to one existing thread or forum post, as well as to a channel or a forum. Use `/content setup changelog-channel` and pick it.

## 🎨 A new look for these announcements
Changelog posts now look like the roster: a gold card with a title and a rule line.

## 📢 For admins
• `/content setup event-forum` now asks which kind it is for (PvP, PvE or PvX). Run it again with the same forum and another kind to share one forum.
• `/content setup clear-event-forum` stops a forum for every kind. Add `forum-type` to stop just one.
• `/content setup cta-role` and `remove-cta-role` manage the roles that can schedule a CTA.
