# 📣 What's new in 0.31.2

Easier setup for event forums and for who can create call-to-arms events.

## 🗂️ One forum for each kind of content
Admins now choose the forum for **PvP**, **PvE** and **PvX** separately. The old "Any" choice is gone. Want PvX events in your PvP forum? Pick that forum for PvX as well. One forum can take as many kinds as you like.
• If a kind has no forum yet, the bot tells you when someone tries to create it, and what to do about it.
• Servers that already had forums set up keep working exactly as before.

## 📣 Choose who can create call-to-arms events
Admins can now add a role right from the setup command, with no extra panel to open. Use **cta-role** to add a role and **remove-cta-role** to take one away. Repeat it to add more roles. Admins can always create call-to-arms events.

## 📢 For admins
• `/content setup event-forum` now asks which kind it is for (PvP, PvE or PvX). Run it again with the same forum and another kind to share one forum.
• `/content setup clear-event-forum` stops a forum for every kind. Add `forum-type` to stop just one.
• `/content setup cta-role` and `remove-cta-role` manage the roles that can create a call to arms.
