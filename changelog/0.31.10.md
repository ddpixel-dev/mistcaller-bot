# 📍 What's new in 0.31.10

## 🏰 ZvZ is now a content type
**ZvZ** is a type of its own, next to PvP, PvE and PvX, with the categories **Faction Warfare, Outpost, Siege, Territory Defense, Castle** and **Other**.
- **Hosts:** pick **ZvZ** in the Type menu of **Plan Content**.
- **Admins:** `/content setup` now accepts `forum-type` **ZvZ**, so ZvZ events can have a forum of their own. Until you set one, creating ZvZ content says so.
- A new **CTA** is now a ZvZ content, so its Type line reads **ZvZ** instead of PvX. CTAs already posted keep their type.
- The old PvP categories ZvZ, Faction Warfare, Outpost and Castle are still there for now.

## 📍 Massing at
Every event, CTA and blank content can now say **where the party gathers**.
- **Hosts:** press **Massing at** on the creation card (or the field in the Blank form), type the place, and it shows under the host on the roster. Change it later in **Manage → Edit → Massing at**. A channel mention works as a link.

## ✨ Cleaner roster
- The "Call to arms" line is gone.
- In events where the host picks the party, the note is now just **Host picks the party**.
- In a CTA, each party and **Bombers** have an icon in the title, with a blank line after each list.
