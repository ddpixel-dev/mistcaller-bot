# 📣 What's new in 0.31.5

A few things hosts asked for, and one fix.

## 👑 Who is hosting
The post and the calendar now show who created the event. In the post it is a **Host** line under the type. In the calendar the host is on each event's details line. It shows a name and never pings anyone.

## ✍️ Assign player and 📨 Review applicants
These are now two buttons in **Manage**.
• **Assign player** puts any server member (or a player waiting as a fill) in an open position.
• **Review applicants** appears in host-picked events and lists only the people who applied. It is dimmed until someone applies.
To decline an applicant, use **Remove player** as before. **Set weapon** moved to the second row of buttons.

## ✏️ Editing events that already started
Hosts and admins can edit an event after it has started again. Leave the start time as it is, or set a new one in the future.

## 🗂️ Depths and Hellgate are PvP
Depths and Hellgate are now PvP categories and are no longer offered for PvE. Events already made as PvE keep their label.
